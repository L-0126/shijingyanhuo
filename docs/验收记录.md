## 离线与部署

三版均通过 file:// 本地双击和 HTTP 静态服务器检查。正文、图片、文楷字体及合成音效均在包内；文化资料的外部原文链接需要联网。网页部署后，首次成功缓存可支持断网刷新；直接双击文件无需预先联网。

限速测试为 200 ms 延迟、128,000 字节/秒下载：正文与字体在 7.23 秒可读，场景在 8.30 秒可操作。

隐藏窗口时，正在进行的行船进度保持 0.022103，输入归零，音频状态为 suspended；恢复窗口后可以继续。

## 性能对照

同一台设备、同一 Chrome、1440 × 1000、第一章概览。每版预热后采样三次，每次 3 秒。各版本采用自己的实际页面布局。任务占比为页面渲染进程的任务时间比例，不是整台设备 CPU 使用率。动画回调间隔来自无界面浏览器，不等同于实体显示器帧率。

| 版本 | 平均任务占比 | 动画间隔中位数 | 动画间隔 P95 | JS 堆内存 |
| --- | ---: | ---: | ---: | ---: |
| v7_0 | 4.14% | 8.30 ms | 8.63 ms | 2.08 MiB |
| v7_1 | 4.33% | 8.30 ms | 8.60 ms | 1.62 MiB |
| v7_2 | 4.16% | 8.30 ms | 8.57 ms | 1.56 MiB |
| v7_3 | 4.18% | 8.30 ms | 8.57 ms | 2.34 MiB |

跟船操作的 20 次输入至下一动画帧中位数为 5.60 ms。首次切镜头后的样本为 746.20 ms，包含首次绘制停顿；后续 19 次最大 6.60 ms。首次进入复杂镜头仍有进一步优化空间。原始测量包含该样本，未删除。
