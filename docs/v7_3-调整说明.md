# v7_3 · 翻页与全屏书本调整

2026-11-11，按本轮反馈调整 `v7_3`。

- 长卷页切换章节时，恢复原有的收起纸片、曲面翻页、展开场景过程。滚动和点击章节入口均使用同一翻页动画。快速连续切章最终停在最后选择的章节。
