## 创作思路

我们从日常生活中的小事展开“市井烟火”：师傅记得熟客的口味，
阿婆托人捎一份菜，茶客给陌生人让出座位，裁缝把旧衣修好，
家人为晚归的人留着饭。这些关系分别落在“味、声、闲、艺、情”五章中。
每一章都安排了一个有开端和回应的小故事，操作的结果会留在场景或随页纸签上。

立体书的形式让不同地方的生活可以并置在同一个跨页里。
建筑、人物和物件由 SVG 图形与分层纸片组成，通过 CSS 三维变换呈现折叠、
展开和翻页。纸张纹理、布面封皮与文楷字体延续书本的视觉形式；
餐票、茶签、衣物补签和家书则把文字放回故事里的物件上。

正文与场景各有阅读入口。长卷提供文化背景，人物故事让读者参与具体动作。
阅读长卷时可以跳到另一章的文章，点击“走进本章”后再切换书中的场景。
这样，读者可以按自己的速度阅读，也可以先动手，再回头了解地方背景。

## 打开

解压压缩包，用 Chrome 或 Edge 打开与本 README 同级的 `index.html`。
无需安装依赖，正文、字体、照片和纸艺均可离线使用。
也可以把本文件夹的所有内容上传到任意静态网站，首页设为 `index.html`。

打开网页时，立体书和对应章节的长卷同时显示。收起长卷后，画面左侧显示“长卷”入口。宽屏上长卷从左侧滑入，书同步等比例横移。手机上的长卷从底部滑入。启用系统的减少动态效果时，开合会直接切换。

点书页外侧可翻到上一章或下一章，长卷会定位到对应正文。滚动长卷跨章或点击栏内章节时，立体书会翻到同一章。同章内收起再打开长卷会保留阅读位置。

## 五章怎样玩

1. 味：选择口味，在碗上绕圈拖动拌面，或按住按钮；拌匀后端给熟客。
2. 声：接下阿婆的菜篮，在操作台向右拖住或按住摇橹按钮。松开后小船有短暂滑行；靠岸后交货。
3. 闲：向右拖动提壶，松开收壶；也可用倾角滑条。添满第一盏后收壶听对话，再续第二盏。
4. 艺：选择补布，从针尖沿破口向右拖，针脚逐段出现。也可按住按钮或逐段缝补；完成后交还旧衣。
5. 情：走到码头登船，随游轮渡江，靠岸后再沿石阶走向院坝。窗口沿途逐段亮起；到家后先放下东西，再落座团圆。

操作台可用 Tab 聚焦。方向键提供等价操作；添茶时左右键调整倾角。
每段故事都有暂停、重新开始、复看。没有分数，也没有限时失败。
切到其他标签页时，场景动画暂停。

## 阅读、镜头和进度

- 点本章可互动的人物可拉近镜头，再点一次回到全书。按住拖动纸件可继续完成故事操作。
- 归家镜头跟随人物和游轮，在登船、靠岸时平滑衔接。第一视角沿设计好的路径和构图展开。
- 阅读长卷中的物件札记时，场景暂停，收起纸页后从原进度继续。
- 分享按钮可定位章节或某一正文段落；浏览器前进、后退可用。
- 支持旧地址 `index.html?chapter=1` 到 `index.html?chapter=5`。
- 本次体验进度保存在页面内存，刷新或关闭后重新开始。
- 本地文件的阅读位置需随整个文件夹分享。部署后可直接分享完整网页链接。

## 90 秒漫游

90 秒漫游展示五个跨页的左右两面。水陆晨集随船连续穿过书缝；山城团圆跟随归家人登船渡江、靠岸上阶，最后来到院坝。其余跨页在两面的主题间移动镜头。
拖动进度条可定位到任意时间，也可暂停、前进或后退 6 秒。
镜头切换主题时，长卷缓动到对应文段。手动滚动长卷或操作书本会暂停漫游。
“复看故事”只播放当前一章。导览期间仍可阅读资料。
系统开启“减少动态效果”时，镜头使用稳定构图，文字与操作结果完整保留。

## 内容与来源

每章保留四节正文、两则物件札记及人物故事，并在文末列出文化资料入口。
正文沿纸页中的店招、物件和人物动作展开，导语与故事对话使用同一叙述风格。
文化来源说明地方背景；店铺组合、人物对话和互动情节属于本书原创演绎。
江南与岭南在书缝两侧相接，是纸艺场景的安排，不表示真实地理路线。
